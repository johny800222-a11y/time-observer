# 時空觀測器：臺灣命運的抉擇

國小五年級社會科（臺灣史）的互動學習遊戲。玩家扮演「歷史觀測者」，以第一人稱連結歷史人物的意識，在場景中和配角對話、蒐集線索，再替關鍵人物下達指令。選對了，歷史照原本的軌道前進；選錯了，會跳出「時空警告」說明為什麼歷史不是這樣走的。知識在探索和抉擇中自然吸收，最後用「歷史修正檢驗」小測驗收成果。

## 怎麼開

- **直接玩**：用瀏覽器打開 `index.html` 就能玩（需要網路才會載入字型，沒網路會改用系統字型）。
- **本機伺服器**：在 `兒童學習/` 資料夾執行 `python3 -m http.server 5173 --directory time-observer`，再打開 http://localhost:5173 。
- 進度（星星、知識卡、關鍵詞）存在這台裝置的瀏覽器裡；要歸零可到遊戲內「設定 → 清除進度」。

## 一個章節怎麼進行

1. **時空跳躍**：年份從今天倒轉到目標年代。
2. **開場旁白**：第一人稱帶入，介紹這次連結的人物。
3. **場景探索 × 3**：點擊人物（頭上有「!」）和物品（「?」）聽對白。帶有線索的對話會收進線索欄，湊滿需要的數量才能「下達指令」。配角平常會冒出閒聊泡泡，主角（腳下有綠色光圈）點了會說出內心話。
4. **抉擇**：三個選項隨機排序。選錯 → 「時空警告」說明原因、歷史穩定度 −15%，可以重選；選對 → 「指令成功」敘述真實歷史，並獲得一張**知識卡**（含「連結今天」，把古蹟、地名連到現在）。
5. **意識跳躍**：遇到時代交替（例如宋克 1625 年過世），會把玩家的意識轉移到下一位人物。
6. **歷史修正檢驗**：5 題段考型態的題目（記憶連結、因果素養、是非思辨……），每題都有解說。
7. **觀測報告**：星等、答對題數、歷史穩定度、本章知識卡與學會的關鍵詞。

對白裡亮黃色的字是**關鍵詞**，點一下會跳出解釋，並自動收進「觀測筆記」。

## 新增一個章節

1. 複製一份現有章節檔（例如 `data/ch03_1624.js`），改名為 `data/chXX_年份.js`，把 `window.GAME_DATA.chapters.ch03` 改成新的 id。
2. 填寫內容：
   - `cast`：角色。`look` 決定外觀，可用的值：
     - `hairStyle`：short / long / womanlong / curly / bun / kidbun / kid / queue（清代辮子）/ chonmage（日本髮髻）/ wild（史前蓬髮）/ bald
     - `hat`：cavalier（荷蘭寬邊帽）/ skullcap / beanie / bandana / wrap（明代頭巾）/ scholar（方巾）/ helmet / soldiercap / liuhe / guapi（瓜皮帽）/ qing（清代官帽）/ turban / straw（斗笠）/ bowler / flatcap / featherband / flowerband / furcap（布農皮帽）/ eaglefeather（排灣熊鷹羽飾）/ amisfeather（阿美羽冠）/ amisband（阿美彩珠頭飾）
     - `outfit`：coat / sailor / robe / qingrobe / magua / qingwoman / armor / suit / kimono / siraya / dress / yong（清兵號褂，`patch` 可改胸前字）/ hide（獸皮衣）/ barkcloth（樹皮布、簡單織布）/ vest（布農長背心）/ tao（達悟背心）/ paiwan（排灣刺繡）/ amis（阿美紅衣）/ worker
     - `beard`：mustache / goatee / vandyke / longbeard / full
     - `acc`（手持物）：map / fan / book / brick / hoe / rake / oar / spear / staff / sword / bow / abacus / basket / scroll / paper / letter / lantern / stonetool（打製石器）/ stoneaxe（磨製石斧）/ woodspear / hammer / fish（飛魚）/ millet（小米）
     - 其他：`bareArms: true`（露出手臂）、`necklace: true`（珠串項鍊）、`earring: 'jade'`（玉玦耳環）
     - `expr`：smile / happy / worry / serious；`kid: true` 會縮小成小孩
   - `scenes`：每個場景的 `bg`（cave / riverside / beinan / shisanhang / mountain / lanyu / slatevillage / amis / deck / tayouan / village / luermen / farmland / temple / yamen / harbor / taipei，或在 `art.js` 新增），可加 `era`（顯示在左上角的年代，例如「3千年前」）、`actors`（人物用 `cast`，物品用 `prop`，`x`/`y` 是 1600×900 畫布上的腳底座標）、`need`（需要幾條線索）、`decision`（恰好一個 `ok: true` 的選項）、`card`（知識卡）。
   - 對白：字串＝被點的角色說；物件 `{ who, text }`，`who` 可以是 `narrator`、`system`、`host`（目前連結的角色內心）或角色 id。
   - 文字中用 `[[關鍵詞]]` 標記，並在 `glossary` 加上同名解釋。
   - `quiz`：選擇題 `{ tag, q, options, answer, explain }`；是非題加 `type: 'tf'`，`answer` 為 `true` / `false`。
   - 章節年代：一般用 `year`（數字，時空跳躍會從今年倒轉到這一年）；史前章節改用 `warpAgo`（例如 30000，會顯示「距今 30,000 年前」），並用 `yearLabel` 寫給人看的年代。
3. 在 `index.html` 和 `artifact.html` 加一行 `<script src="data/chXX_年份.js"></script>`。
4. 把 `data/curriculum.js` 裡該章的 `status` 改成 `'play'`，並確認 `books` 的單元與月份。

## 和原始雛形相比的史實校正

- 1624 年把荷蘭人趕出澎湖的是**明朝**，不是清朝（清朝 1683 年才來臺）。
- 宋克是荷蘭東印度公司派駐臺灣的**首任長官**（艦隊指揮官），1625 年就在臺灣過世；1627 年起在新港社傳教、發展羅馬字的是傳教士**甘治士**等人，所以第三幕改由「意識跳躍」換成甘治士。
- 1624 年西班牙人還沒到北臺灣（1626 年占雞籠、1628 年占淡水），選北部的警告改成「兩年後西班牙人就會占領北部」。
- 鹿皮主要外銷**日本**，不是歐洲。
- 熱蘭遮城 1624 年動工時叫「奧倫治城」，1627 年改名。

## 第 1、2 章的設計說明

- **第 1 章**用「工具演進」貫穿四個時代：打製石器（長濱）→ 陶器與磨製石器（大坌坑）→ 玉器與石板棺（卑南）→ 煉鐵（十三行）。錯誤選項刻意放「別的時代才有的技術」，選錯時的說明就是在教時代順序。史前人物沒有留下名字，遊戲開頭會告訴孩子名字是觀測器取的。
- **第 2 章**以課本的「原住民族與自然環境」為主軸：布農族（山：輪耕）、達悟族（海：飛魚季規範）、排灣族（住：就地取材的石板屋）、阿美族（社會：年齡階級）。角色只用族群和身分稱呼，不虛構個人姓名；每張知識卡的「連結今天」都寫現在仍在舉行的祭典或保存的聚落，避免讓孩子以為原住民族文化只存在過去。結尾也介紹名稱的演變（生番／熟番 → 高砂族 → 山地同胞 → 原住民族）與 8 月 1 日原住民族日。
